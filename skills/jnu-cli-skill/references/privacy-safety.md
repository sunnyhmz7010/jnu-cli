# 隐私与安全

本 Skill 会处理用户账号中的校园数据。只读取和展示足以回答当前问题的数据。

## 凭据与登录态

- 不要索取用户密码。
- 不要索取 Cookie、令牌、浏览器 profile、trace、截图或 HAR 文件。
- 只通过 `jnu-cli` 使用持久化浏览器 profile；不要在 Skill 中自行管理登录态。
- 用户在 `auth login` 打开的独立浏览器窗口中完成正常认证；CLI 会验证本科课表，并重开同一档案确认会话可复用。
- 默认目录为 `~/.jnu-cli/`，可用 `JNU_CLI_HOME` 指定；不要删除用户日常浏览器或 CLI 的档案来处理网络错误。

## 隐私数据

- 将成绩、绩点、考试、学生身份、评教和学业完成情况视为隐私。
- 除非用户明确要求且 CLI 已返回，否则不要展示姓名、学号、内部 ID 或原始用户资料。
- 只概述当前任务需要的字段，不在 Skill 目录中保存用户画像或查询结果。
- 数量、状态、剩余值或筛选后的子集足够回答时，不要粘贴完整记录。
- `profile show` 和 `profile status` 只查询本人，不接受他人学号。`status` 只返回学籍摘要；`show` 包含已核对页面的证件、电话、邮箱和家庭地址，仅向用户回显当前请求需要的字段。
- 不将完整个人信息结果或证件、联系方式写入日志、测试夹具或 Skill 文件；CLI 不输出隐藏记录标识、银行卡和原始档案。

## 能力边界

- 教务命令只读；不提交评教、修改资料、重算学业结果或进行课程认定。
- 不在 Skill 内另行抓取网页、调用隐藏接口或伪造未支持的命令。
- 不绕过认证、验证码、网络限制、限流或访问控制。
- 安装和登录按用户授权执行；不静默安装 CLI 或浏览器。
